Introduction

O'qituvchi telefoni, sinf doskasi va admin panel ishlatadigan API.

Base URL: http://localhost:8000 
Barcha so'rov va javoblar JSON. Server manzili: `http://<kompyuter IP>:8000/api`.

- **Kirish:** `POST /api/login` → `token`. Keyingi so'rovlarda `Authorization: Bearer <token>`.
- **Doska** (login yo'q): `POST /api/boards` sessiya ochadi va `token` qaytaradi; doska `board.{token}` Reverb kanalini tinglaydi (`board.updated`, `board.controller-seen`).
- **Telefon pult sifatida:** `POST /api/boards/pair` (6 xonali kod), keyin `commands`, `heartbeat` (har 15 s), `controller-state`.
- **Offline baholar:** `POST /api/sync` — `client_uuid` bilan, har biri faqat bir marta qo'llanadi.
- Xatolar: 422 — validatsiya (`errors`) yoki dars oqimi xatosi (`code`: `no_students_left`, `answer_pending`, `answer_closed`, ...); 401 — token yo'q/eskirgan; 403 — ruxsat yo'q.

Hujjat koddan yaratiladi: `php artisan scribe:generate` (backend papkasida).

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Token POST /api/login javobida keladi (token). Doska endpointlari (login yo'q) belgilab qo'yilgan.
